# GFT - Workshops 
## Design Patterns

## Comenzando 🚀

_El repositorio contiene todos los ejercicios que se desarrollan dentro del taller. Se recomienda iniclamente el clonado de la rama "develop" para tener el código base del proyecto y a partir de ahi descagar el resto de las ramas, donde cada una de las ramas adicionales a excepción de "master, representa la implementación de un patron de diseño."_

```
git clone -b develop https://github.com/devhomer/gft-workshops-design_patterns.git
```

### Pre-requisitos 📋

_A pesar de que los patrones de diseño pueden ser aplicables en distintos lenguajes de programación, en este taller en especifico se realizaran con java. Es importante veirifacar que se tenga instalado un JDK igual o superior a la versión 8_

```
java -- version
```
